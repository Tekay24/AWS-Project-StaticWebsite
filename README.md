# ☁️ AWS Serverless Cloud Deployment Project

A collaborative project to design, build, and deploy a fully functional web application on a cloud-native AWS infrastructure.

## 📌 Project Overview
The goal of this project was to move away from traditional hosting and deploy a web application using a serverless architecture on AWS. The system includes a dynamic frontend that interacts with a NoSQL database to manage user data and bookings.

## 🏗️ AWS Architecture & Tech Stack
- **Cloud Provider:** AWS (Deployed on Free Tier)
- **Database:** Amazon DynamoDB (NoSQL)
- **Backend:** Python (AWS Lambda / API Gateway)
- **Frontend:** HTML, CSS, JavaScript
- **Version Control:** Git & GitHub (Collaborative workflow with branching and pull requests)

## 🚀 Why Serverless? (Technical Decisions)
- **Scalability:** Chose DynamoDB to ensure the database can handle sudden spikes in traffic without manual server provisioning.
- **Cost-Efficiency:** Utilized AWS Free Tier services to prove that a highly available application can be run with zero upfront infrastructure costs.
